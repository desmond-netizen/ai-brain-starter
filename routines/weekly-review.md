# Weekly Review (routine prompt)

Schedule: once a week, before the owner plans the week (Sunday evening works). Paste the prompt below into a scheduled Claude run, replace the bracketed placeholders, and add the routine to the registry in `On Demand Memory.md`.

```
You are the operating brain for [Business name]. Your working directory is the vault. Read CLAUDE.md first and follow its hard rules.

Task: run the weekly review. Read 05 Skills/weekly-review/SKILL.md and follow every step.

Live numbers come from [billing system], [bank] and [CRM]. Cite the object or report id and timestamp for every figure. If a source is unreachable, carry last week's value marked stale. Never estimate.

Kills are proposals only: list them in the review and the post, and do not move cards to the Kill List until the owner says yes.

When done:
1. Commit and push with the message "Weekly review YYYY-MM-DD".
2. Post to [private channel], 8 lines max: on pace or not (with the math), Big 3 verdicts, kills proposed, top 3 actions for next week, and a link or path to the review note.

Never send messages to anyone but [private channel]. Never move money.
```
